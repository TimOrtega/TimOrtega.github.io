The story

I designed and built a GUI-based incremental game in Java using Swing. The project gave me a way to practice object-oriented design while building something interactive, with progression driven by player input and timers.

Project focus
  • Class hierarchies & encapsulation
  • Event listeners & timers
  • External upgrade definitions
Read the story ↓
01 / Software structure

Build behavior
from reusable parts.

I applied class hierarchies and encapsulation to organize the game. Swing provides the interface, while event listeners handle player interaction and timers drive automated progression.

Those pieces separate the program’s responsibilities: what the interface displays, how a player interacts with it, and how the game changes over time.

02 / Data-driven upgrades

Add content without
rewriting the logic.

I built a file-reading system that loads upgrade definitions from external text files. This allows new upgrades to be added without changing the code.

The project connected object-oriented design with practical extensibility: the underlying behavior can stay stable while the game’s content grows.
